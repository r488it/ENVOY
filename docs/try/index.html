アプリと同じ見分け

詐欺の電話を試す

AgentPhone のリゲルは、知らない電話に代わりに出て、相手の言葉から詐欺の疑いを見分けます。その見分けを、このページで試せます。キーも登録も要りません。見分けは、このページの中だけで行います（どこにも送りません）。

    選んだ台本を、相手の言葉として 1 行ずつ流します。

    「始める」を押し、リゲルが名乗ったら、上の台本を声に出して読んでください（あなたが電話の相手の役です）。声の聞き取りは、ブラウザの音声認識を使います（Chrome は Google、Safari は Apple に声が送られます）。見分けは、このページの中だけで行います。

    試しの電話（本物の電話ではありません）
    通話のやり取り（文字）

    本物の電話では、リゲルが代わりに出て、AI だと名乗って用件を聞き、相手の言葉が届くたびに、このページと同じしくみで詐欺の疑いを見分けます。Android のスマホがあれば、アプリの 設定 › 電話 › 「詐欺の電話を試す」 で、同じことをスマホの中で試せます。

    AgentPhone（GitHub） ・ 台本の一覧 ・ アプリ（Releases）

    見分けは、言い回しの決まり（お金の話・大事な番号を聞く・急がせる・警察などを名乗る・おどす・秘密にさせる・身内を名乗る・自動音声）に当たるかを見るだけなので、「詐欺です」とは言い切りません。台本と人の名前・会社・番号は、すべて作り話です。
