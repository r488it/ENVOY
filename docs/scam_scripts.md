# 詐欺の電話の台本（試し用）

AgentPhone（ENVOY MCP）の「詐欺の電話を試す」で、声に出して読むための台本です。README の「評価」で使った 60 本と同じものです。

> [!NOTE]
> すべて作り話です。人の名前・会社・番号は実在しません。警察や役所などを名乗るのは、詐欺の手口として書いたものです。台本は、見分けの規則を見ていない Claude Code のサブエージェントが、警察庁などが公開している手口の説明をもとに書きました。

## 試し方

1. ENVOY MCP を Android（12 以降）に入れる（[Releases](https://github.com/r488it/ENVOY/releases)）
2. ENVOY MCP を開き、設定 › 「電話」 › 「詐欺の電話を試す」 › 「始める」
3. リゲルが名乗ったら、下の台本の言葉を、上から順に声に出して読む（1 行読んだら、少し間を空ける）
4. 読み終えたら、赤いボタンで終える。詐欺の疑いの帯と、結果が出ます

腕のボード・API キー・アカウントは要りません。本物の電話はかけません。「文字のときの結果」は、台本を文字のまま見分けたときの結果です。声で読むと、聞き取りの違いで変わることがあります。
